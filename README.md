# ChainRipple

Transfers and reconciles cryptocurrency transactions across multiple blockchain networks with real-time updates.

With ChainRipple, you get a lightweight tool that stays out of your way.

**What you get**

- Transfers and reconciles cryptocurrency transactions
- across multiple blockchain networks with
- real-time updates

## Key Features

- Transfers and reconciles cryptocurrency transactions
- across multiple blockchain networks with
- real-time updates

## Technology Stack

- typescript
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/ChainRipple.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
